# 💡 Sobre el Proyecto
El objetivo principal de este sitio es construir una web sólida y atractiva, cuidando tanto la experiencia de usuario en computadoras como en dispositivos móviles.
# ¿Qué incluye este desarrollo?
* **Estructura HTML5 semántica:** Código ordenado, claro y accesible.
* **Diseño adaptativo (Responsive):** Maquetación fluida usando el sistema de grillas de Bootstrap y estilos personalizados en CSS.
* **Componentes clave:** Barra de navegación, sección de presentación ("Sobre Mí") y distribución en columnas.
* **Flujo de trabajo profesional:** Control de versiones con Git, ramas (`feature branches`) y commits descriptivos.
